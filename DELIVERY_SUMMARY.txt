================================================================================
ARCHITECTURE
================================================================================

COMPONENT HIERARCHY:

PianoRollEditorView (Main Container)
├── CustomScrollView (Grid) → NoteGridView
│   └── NoteView (multiple instances)
├── CScrollView (Timeline) → TimelineView
├── CScrollView (Keyboard) → KeyboardView
└── ControlPanelView

DATA MODEL (Framework Independent):
- NoteModel: MIDI note representation
- PRESequence: Collection of notes
- NoteGridStyleSheet: Visual configuration

FRAMEWORK TRANSLATION:
JUCE Component → VSTGUI CView
JUCE Graphics → VSTGUI CDrawContext
JUCE Colour → VSTGUI CColor
JUCE Viewport → VSTGUI CScrollView
JUCE MouseEvent → VSTGUI CPoint & CButtonState

USAGE EXAMPLE
================================================================================

#include "VSTGUIPianoRollEditorView.hpp"

// Create editor
auto* editor = new PianoRollEditorView(CRect(0, 0, 800, 600));

// Setup: 10 bars, 900 pixels/bar, 20 pixels/note
editor->setup(10, 900, 20);

// Set MIDI callback
editor->sendChange = [](int note, int velocity) {
    // Handle MIDI output
};

// Load sequence
PRESequence seq;
seq.events.push_back(NoteModel(60, 100, 0, 480, {}));
editor->loadSequence(seq);

// Get result
PRESequence result = editor->getSequence();
